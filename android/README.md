# ProctorX Android Wrapper

This Capacitor project was generated to validate the Android wrapper structure and its native permission declarations. It was generated with a placeholder HTTPS host and **must not** be released as-is.

Before building or opening it for a real device, set the published production URL and re-sync the web assets:

```bash
export PROCTORX_ANDROID_SERVER_URL="https://your-published-proctorx-domain"
pnpm android:sync
pnpm android:open
```

The runtime permission prompts remain candidate-controlled. Run the device matrix in `../ANDROID_CAMERA_MICROPHONE_COMPATIBILITY.md` on a physical Android device before producing a signed APK.
